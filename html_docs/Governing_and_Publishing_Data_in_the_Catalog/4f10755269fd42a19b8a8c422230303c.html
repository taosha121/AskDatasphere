Migrating Catalog Content

When organizations transition from a standalone SAP Datasphere setup to a SAP Business Data Cloud setup, catalog content is automatically migrated from SAP Datasphere to SAP Business Data Cloud.

To monitor the migration progress and retry failed steps, go to SAP Datasphere and access the Metadata Extractions page. For the SAP Datasphere system, you can select Monitor Catalog Migration to open the Monitor Catalog Migration dialog.

Note

During the catalog migration, personal data in the form of user favorites will also be migrated.

The following table provides a description of each migration step.

Migration Step

Description

 Connected Systems

Displays the catalog connection status for source systems that are included in the catalog migration. This list consists of the SAP Datasphere system that is in the formation and SAP Analytics Cloud and BW (SAP Datasphere, SAP BW bridge or SAP BW∕4HANA) systems that are connected to the catalog via SAP Datasphere.

 Extracted Objects
Displays the synchronization status and object totals for systems that are automatically synchronized during the catalog migration. For systems that you manually have to synchronize, the status is Check extraction.

  • Synchronizations for connected SAP Datasphere and SAP Analytics Cloud systems are automatically started after the SAP Datasphere system is added to the SAP Business Data Cloud and the connection completed.

  • Synchronizations for connected BW systems must be manually run. Close this dialog, which returns you to the Metadata Extractions page. Find the system in the list of systems and manually synchronize it.

The objects extracted to the catalog are based on the access permissions of the authorized user for the source system.

Tip

When you access the catalog search page from SAP Business Data Cloud, you'll be able to see objects that have migrated.

 Tag Hierarchies and Tags

Displays the status and totals for migrating tag hierarchies and tags.

 Glossaries, Terms, and KPIs

Displays the status and totals for migrating glossaries, terms, and KPIs.

 User Favorites

Displays the status and totals for migrating user favorites.

 Summary and Confirmation

Provides a final checkpoint where you review the migration outcome and confirm it. Before confirming the migration, check the migration summary logs and the object extractions for each system. If you are satisfied with the catalog migration, you can confirm the migration outcome.

Tip

As a best practice, go to the catalog search page and randomly review the objects to see if they migrated as expected.
