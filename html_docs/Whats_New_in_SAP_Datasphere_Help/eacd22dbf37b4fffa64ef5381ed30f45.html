How to Use the SAP Datasphere What's New Viewer

The scope of SAP Datasphere is steadily increasing as we add new features on a regular basis. We keep you updated on these changes with our What’s New content. With the What's New Viewer you can easily find and share the content that is relevant for you.

Shaping, Sharing, and Saving Your Results

When using the What’s New viewer, you can shape the content that you want to see according to your needs, share your results, and save your preferences for later.

Switching between Tabular and List View of the Content

By default, the content is displayed in a chronological view of the content. You can use the Tables View button in the header bar to switch to a table view of the content and switch back by using the List View button.

Filtering and Sorting

To filter the content, select one or more values from the filters for Category, Version, and Release Date.

In the tabular view, the content initially is sorted by version and category. You can change the sort order for all columns except Title and Description. To change the sort order, select the relevant column heading. When you do, an arrow facing up or down indicates whether the sort direction is ascending or descending.

You can also reset the filter and sorting to their initial default setting or clear all filters by using the corresponding buttons to the right of the filters.

Searching

If you are interested in content containing a specific string of text, you can type it into the search bar and choose the Search button or press Enter.

When you do, a yellow bar indicating that you have performed a search is displayed at the top of the What's New Viewer. Only entries containing the text string are displayed. All instances of the text string are highlighted.

You can undo the selection by choosing X in the search bar.

Note

If you can’t find what you are looking for, it could be because a (preset) date range or some other filter is preventing you. Check the date range being applied or use Reset to Initial or Clear All to remove any impacting filters before trying your search again.

Showing or Hiding Columns

In the tabular view, if there are columns of data that don’t interest you, use the Hide/Show Columns button on top of the table to suppress them or to display columns that are not shown in the initial default setting.

Changing the Number of Entries Shown per Page

Initially, the number of entries shown per page is 25. To adjust the number returned, use the Show Entries selection on top of the content.

Saving or Sharing a Selection

When making a selection by filtering or searching for a text string, your preferences are appended to the URL for the page.

If you find yourself reapplying the same filter configuration each time you visit the What's New Viewer, consider using the Favorite button to save your preferences. Later, you can find your favorites on your SAP Help Portal profile (click the avatar icon at the top right corner to access the Your Profile link).

You can also save the URL as a browser bookmark, copy/paste it into other contexts, or use the Share button to share your selection with others.

Downloading a Selection

In the tabular view, you can download your selection as a CSV file that can be opened using a spreadsheet application such as Microsoft Excel.

Values for Category, Action, and Type

Learn about the values of the Category, Action, and Type attributes used in the What's New Viewer.

Attribute/Column Available in Label Descriptions
Category Table view and list view

Indicates the overall feature or feature set. The values correspond to the categories used in the SAP Roadmap.
Action Table View (hidden by default) and list view

Indicates the level of disruption to your processes and whether you're required to take any actions. The values are:

  • Required

    Indicates a high disruption. An action must be taken by the Valid as Of date. If no action is taken, the process may break or change.

  • Recommended

    Indicates a medium or low disruption. To adopt the feature, function, or process, an action must be taken by the Valid as Of date. If no action is taken, the old feature, function, or process remains active, but your user experience may be broken.

  • Info only

    Indicates a zero or trivial disruption. The feature, function, or process is now available, and no action is required to use it.
Type Table View (hidden by default)

Indicates if the What's New content is for a new or existing feature or if something important is to be announced. The values are:

  • New

    Indicates that the What's New content is for a new feature, function, or process, that didn't exist before.

  • Changed

    Indicates an enhancement, bugfix, deprecation, deletion, or any other change to an existing feature, function, or process,.

  • Announcement

    Used for important announcements that aren't related to new and changed features.
