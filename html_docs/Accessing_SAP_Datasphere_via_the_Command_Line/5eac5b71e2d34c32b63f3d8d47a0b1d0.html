Manage Spaces and Space Access via the Command Line

Users with an administrator role can use the datasphere command line interface to create, read, update, and delete spaces. Users with a space administrator role can update some space properties, add (or remove) users, database users and HDI containers, and delete spaces.

Objects

Command

Spaces

datasphere spaces

See Managing Spaces via the Command Line.
Note

The commands datasphere spaces create and datasphere spaces delete are not supported for file spaces (spaces with a storage type of SAP HANA Data Lake Files).

Space Users

datasphere spaces users

See Managing Space Users via the Command Line.

Database Users

datasphere dbusers

See Managing Database Users via the Command Line.
Note

The datasphere dbusers <command> commands are not supported for file spaces (spaces with a storage type of SAP HANA Data Lake Files).

Priorities and Statement Limits

datasphere workload

See Managing Priorities and Statement Limits for Spaces or Groups via the Command Line.
