Managing the Data Marketplace via the Command Line

Users with a modeler role can use the datasphere command line interface to manage the Data Marketplace.

Command

Data Marketplace data providers

datasphere marketplace providers

See Managing Data Marketplace Data Providers via the Command Line.

See Managing Data Marketplace Data Products via the Command Line.

Data Marketplace licences

datasphere marketplace licenses-by-provider

See Managing Data Marketplace Licenses via the Command Line.

Data Marketplace data product releases

datasphere marketplace releases

See Managing Data Marketplace Releases via the Command Line.

Data Marketplace contexts

datasphere marketplace contexts-by-provider

See Managing Data Marketplace Contexts via the Command Line.
