What's New in SAP Data Warehouse Cloud 2021 to 2023.5 (Archive)

Find an archive of SAP Data Warehouse Cloud What's New information from 2021 to 2023.5.

To get an overview of the latest new and changed features, see the new format of What's New in SAP Datasphere.

The new format for delivering What's New information allows you to interact with the content using filtering and sorting. You can examine your results in either a chronological or tabular view, export them to CSV, and share them. For your convenience, the new format includes What's New information from 2022 to the most recent version of SAP Datasphere.
