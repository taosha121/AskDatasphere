General Remarks

This documentation covers the following topics:

  • Install and How to Use Content describes how to get the content and install it in the system.

    Caution

    As of the Q4 2020 release, SAP Analytic Cloud content corresponding to the SAP Datasphere models is provided in separate packages in the SAP Analytic Cloud Content Network. You need to import and setup both SAP Datasphere and SAP Analytics Cloud packages for an End-2-End content experience.

    Please read this chapter carefully, even if you have installed content before.

  • Lines of Business (LoB) describes the detailed documentation of the Line(s) of Business (LoB) and Industries are described in Industries. Cross Application content is described in Cross Applications.
  • Find information about known issues and their resolution in Known Issues.

Further information is available on the following web sites:

  • SAP Community blog,
  • the product web site
  • find an overview of all content packages in the SAP Business Content Center.

This documentation assumes that the reader is familiar with SAP Datasphere. It does not substitute SAP Datasphere documentation, which can be found here: Help Portal: SAP Datasphere.

The content does not include any predefined roles or permissions.
