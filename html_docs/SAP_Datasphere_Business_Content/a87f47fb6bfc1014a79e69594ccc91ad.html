Valid from / to SAP Datasphere version

The view SAP_FIN_CS_HL_HierNode_GrpJrnlEntryItm from the package “Group Reporting for SAP S/4HANA and SAP S/4HANA Cloud” may show unexpected data, because a join condition is incomplete.

The issue will be resolved in release 1.0.1 or any subsequent versions.

To fix the issue in your instance, you can follow these steps:

  • Please navigate to view the join node “Join 2” (Projection 1 – ConsProfitCenterFilter) in view SAP_FIN_CS_HL_HierNode_GrpJrnlEntryItm and add a mapping “Partner profit center” to “Partner profit center”.

  • In join node “Join 3” (Projection 2 - ConsSegFilter), please add a mapping from “Partner segment for segmental reporting” to “Partner segment for segmental reporting”. Once you're done, deploy the changes.

2021.19 -

One of the following content packages cannot be deployed:

  • Finance for SAP S/4HANA Cloud

  • Financial Analytics Dashboard for SAP Analytics Cloud

  • SAP Intelligent Real Estate

  • Solution Order Analysis for SAP S/4HANA Cloud.

The deployment fails with an error like or similar to the following: Datatype string(5) of attribute 'XYZ' in CSN Document does not match to datatype int(2) of target table.

You have updated your DP Agent version from < 2.5.5 to 2.5.5 or newer

If you had previously imported one or several of the mentioned packages from a content release <= 2022.Q3 and with a DP Agent version < 2.5.5, a boolean value got a wrong data type in SAP Datasphere.

(For SAP_FI_SemTagGLAccount the length of two attributes have been shortened).

You have by now updated to a new version of the DP Agent (>= 2.5.5). This results in the usage of the expected data type in SAP Datasphere. These changes can possibly affect the following remote tables:

  • SAP_FI_CompanyCode

  • SAP_FI_Costcenter

  • SAP_FI_FiscalYearPeriodVariant

  • SAP_FI_GLAccount_LineItem

  • SAP_FI_GLAccount

  • SAP_FI_PlanningCategory

  • SAP_FI_PlanningEntryItem

  • SAP_FI_SemTagGLAccount

In case you have replicated data into these tables, delete the data and re-deploy these tables and any other not yet deployed object of your content package.
